# Engineering Reviews

## Purpose

Review records preserve the evidence behind merge readiness. They evaluate the
change, not the author, and complement pull-request discussion when a durable
repository record is useful.

## Use

Use [REVIEW-TEMPLATE.md](REVIEW-TEMPLATE.md) for significant task reviews or
when a task requires a review record. State one decision: Approved, Approved
with comments, or Changes requested. Findings must be evidence-based; optional
scores never replace the decision and supporting findings.
